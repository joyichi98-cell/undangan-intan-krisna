# Undangan Pernikahan Online

Satu berkas `index.html`, tanpa build dan tanpa dependensi.

## Nama tamu
Tambahkan `?to=Nama-Tamu` di akhir tautan, contoh:
`https://nama-proyek.vercel.app/?to=Hanifah-YHPN`

## Yang perlu diganti di index.html
- Nama mempelai, orang tua, tanggal, jam, lokasi
- Nomor rekening (cari "Bank Contoh")
- Tautan siaran langsung (cari "youtube.com")
- Nomor WhatsApp: variabel `whatsapp` di bagian `CFG` pada script
- Waktu hitung mundur: `target` di `CFG`
